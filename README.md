# Portfolio — Julien ROULLET

Portfolio personnel : présentation, suite REKA, projets et activité GitHub.

Site statique, sans étape de build : `index.html`, `style.css`, `main.js` et `assets/`.
Les projets, les langages, les statistiques et le graphe de contributions sont chargés depuis GitHub au chargement de la page (pseudo dans `main.js`).

## Voir en local

```bash
python3 -m http.server 8000
```

Puis ouvre <http://localhost:8000>.
